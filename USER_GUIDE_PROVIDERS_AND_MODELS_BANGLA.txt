1. PROJECT OVERVIEW & INTRODUCTION / প্রজেক্ট পরিচিতি ও সারসংক্ষেপ
================================================================================
[ENGLISH]
Jakariya AI Studio is a unified desktop AI workstation that connects 9 top-tier 
AI providers, an autonomous ReAct multi-step agent with tool execution, continuous 
live voice conversation with active barge-in support, real-time web search, interactive 
smart document preview cards, and 6-format document exporting into a single cohesive app.

[বাংলা]
জাকারিয়া এআই স্টুডিও হলো একটি শক্তিশালী অল-ইন-ওয়ান ডেস্কটপ এআই ওয়ার্কস্টেশন। 
এখানে বিশ্বের সেরা ৯টি এআই প্রোভাইডার, স্বায়ত্তশাসিত রিঅ্যাক্ট এআই এজেন্ট (টুল এক্সিকিউশনসহ), 
লাইভ ভয়েস কনভার্সেশন (বার্জ-ইন সুবিধাসহ), রিয়েল-টাইম ওয়েব সার্চ, স্মার্ট ডকুমেন্ট প্রিভিউ 
কার্ড এবং ৬টি ফরম্যাটে এক্সপোর্ট সিস্টেম একসাথে যুক্ত করা হয়েছে।

3. ADVANCED FEATURES & USAGE / উন্নত ফিচারসমূহ ও ব্যবহারের নিয়ম
================================================================================

[A] AUTONOMOUS RE-ACT AGENT & TOOL EXECUTION
--------------------------------------------------------------------------------
* English:
  - Enter any complex multi-step request (e.g., "Search the web for the latest tech news 
    and export a 2-page executive summary to Word docx and PDF with colorful theme").
  - The AI Agent creates an actionable execution plan, calls tools (web_search, 
    export_document, python_interpreter, file_io), verifies results, and shows the full 
    output both in chat and saved to disk.
  - Multi-Color Document Themes: vibrant, colorful, emerald, sunset, cyber, executive.
* বাংলা:
  - যেকোনো জটিল বহু-ধাপ বিশিষ্ট নির্দেশ দিলে (যেমন: "আজকের তাজা প্রযুক্তি খবর সার্চ 
    করে একটি সুন্দর রঙিন ওয়ার্ড ও পিডিএফ রিপোর্ট তৈরি করো") এআই এজেন্ট স্বয়ংক্রিয়ভাবে 
    টুল ব্যবহার করে সম্পূর্ণ কাজ সম্পন্ন করবে এবং লোকাল ডিস্কে সেভ করবে।
  - রঙিন থিমসমূহ: vibrant, colorful, emerald, sunset, cyber, executive.

[B] CONTINUOUS LIVE VOICE WITH BARGE-IN (⚡ Live Mode)
--------------------------------------------------------------------------------
* English:
  - Click the "⚡ Live" button to start continuous, hands-free voice dialogue.
  - Barge-In Feature: You can speak and interrupt the AI assistant while it is speaking! 
    The app dynamically manages microphone gain (`0.15` attenuation during playback) 
    to eliminate speaker echo while detecting user speech.
  - Full native support for Bangla (বাংলা) and English.
* বাংলা:
  - "⚡ Live" বাটনে ক্লিক করে হাত ছাড়া সার্বক্ষণিক লাইভ ভয়েস চ্যাট করুন।
  - বার্জ-ইন (Barge-In) সুবিধা: এআই কথা বলা অবস্থাতেও আপনি কথা বলে তাকে থামাতে পারবেন।
  - বাংলা ও ইংরেজি উভয় ভাষায় সাবলীল ভয়েস ইনপুট ও আউটপুট সমর্থন করে।

[C] REAL-TIME SUB-SECOND WEB SEARCH
--------------------------------------------------------------------------------
* English:
  - Real-time questions (current news, weather, stock prices, live scores) automatically 
    trigger live web search via Tavily API, Brave Search API, or DuckDuckGo.
* বাংলা:
  - সাম্প্রতিক খবর, আজকের আবহাওয়া বা স্টক প্রাইস সম্পর্কে প্রশ্ন করলে স্বয়ংক্রিয়ভাবে 
    ইন্টারনেট সার্চ করে নির্ভরযোগ্য সোর্স লিঙ্কসহ সঠিক তথ্য দেবে।

[D] 6-FORMAT CONVERSATION & DOCUMENT EXPORTER
--------------------------------------------------------------------------------
* Formats Supported / সমর্থিত ফরম্যাট:
  1. PDF Document (.pdf) - Multi-colored headings, styled tables, callouts
  2. Microsoft Word (.docx) - Custom typography, XML shaded table cells
  3. Microsoft Excel (.xlsx) - Styled spreadsheet with header fills and borders
  4. Web Page (.html) - Responsive CSS variables and dark/light palettes
  5. Markdown (.md) - Clean GitHub flavored formatting
  6. Plain Text (.txt) - Universal plain text
* Features / বৈশিষ্ট্য:
  - Retains rich styling, tables, code highlighting, and Unicode/Bangla text.
  - One-click copy and download buttons on every code block.

[E] AUTOMATIC FAILOVER & ZERO-CRASH ENGINE
--------------------------------------------------------------------------------
* English:
  - If a selected provider runs out of rate limits (HTTP 429) or faces network issues, 
    the engine seamlessly catches the exception and routes the request to an 
    active backup provider without interrupting your chat session.
* বাংলা:
  - কোনো প্রোভাইডারে সার্ভার সমস্যা বা রেট লিমিট শেষ হলে অ্যাপ না আটকে স্বয়ংক্রিয়ভাবে 
    ব্যাকগ্রাউন্ডে সচল ব্যাকআপ প্রোভাইডারে স্যুইচ করে উত্তর প্রদান করবে।

================================================================================
4. QUICK START & CONFIGURATION / দ্রুত চালু ও কনফিগারেশন গাইড
================================================================================

1. Launching the App / অ্যাপ চালু করা:
   - Run from installed Windows Shortcut: Double-click "Jakariya AI Studio"
   - Or run from source terminal / সোর্স কোড থেকে:
     & .\.venv\Scripts\python.exe main.py

2. Configuring API Keys / এপিআই কি (API Key) সেটআপ:
   - Open Settings UI inside the app (Gear Icon ⚙️ at header or status bar).
   - Go to "AI Providers" tab and paste your API keys.
   - Click "Save" — keys are securely loaded into the runtime configuration.

3. Testing Live Connections / সংযোগ পরীক্ষা:
   - Inside the Settings "AI Providers" page, click "Test Connection" on any provider 
     to verify instant live connectivity.
