1. PROJECT OVERVIEW & INTRODUCTION / প্রজেক্ট পরিচিতি ও সারসংক্ষেপ
================================================================================
[ENGLISH]
Jakariya AI Studio is an enterprise-grade, all-in-one desktop AI workstation designed 
to eliminate vendor lock-in, maximize productivity, and guarantee complete user data privacy. 
Built on Python and PySide6 (Qt6), it integrates 16 premier cloud and local AI engines, an 
autonomous multi-turn ReAct agent with 12 sandboxed tools, continuous hands-free live voice 
dialogue with active barge-in support, hardware audio device selectors, FLUX.1 ultra-HD image 
generation (with same-type companion art synthesis), smart Claude-style interactive document 
preview cards, 8 physical export formats (PDF with Bengali font embedding, DOCX, XLSX, HTML, 
MD, TXT, CSV, JSON), and 4 curated eye-comfort theme palettes.

[বাংলা]
জাকারিয়া এআই স্টুডিও (Jakariya AI Studio) হলো একটি প্রিমিয়াম এন্টারপ্রাইজ-গ্রেড অল-ইন-ওয়ান 
ডেস্কটপ এআই ওয়ার্কস্টেশন। এটি ১৬টি বিশ্বসেরা ক্লাউড ও লোকাল এআই ইঞ্জিন, ১২টি সুরক্ষিত টুলস-সমৃদ্ধ 
স্বায়ত্তশাসিত রিঅ্যাক্ট (ReAct) এআই এজেন্ট, হ্যান্ডস-ফ্রি লাইভ ভয়েস কনভার্সেশন (বার্জ-ইন ইন্টারাপশনসহ), 
মাইক্রোফোন ও স্পিকার হার্ডওয়্যার ডিভাইস সিলেক্টর, FLUX.1 আল্ট্রা-এইচডি ইমেজ জেনারেশন (একই ধরণের ছবি তৈরি 
সুবিধাসহ), ক্লদ-স্টাইল স্মার্ট ডকুমেন্ট প্রিভিউ কার্ড, ৮টি ফরম্যাটে এক্সপোর্ট সিস্টেম (বাংলা ফন্ট এমবেডেড 
পিডিএফ, ওয়ার্ড, এক্সেল, এইচটিএমএল, ইত্যাদি), এবং চোখের জন্য আরামদায়ক ৪টি আধুনিক থিম একসাথে যুক্ত করেছে।

3. IMAGE GENERATION & SAME-TYPE IMAGE STUDIO / ইমেজ জেনারেশন ও ছবি তৈরি
================================================================================
[ENGLISH]
1. Text-to-Image Generation:
   - Type any natural prompt (e.g. "Create an ultra-HD portrait of an astronaut on Mars" or 
     "একটি সুন্দর আধুনিক ঢাকার ডিজিটাল আর্ট তৈরি করো").
   - The studio dispatches the request to FLUX.1-schnell or Stability AI and displays a 
     high-resolution preview card with an embedded "💾 Save Image" action.
2. 🎨 Same-Type / Similar Image Generation (NEW in v2.0.0):
   - Attach an existing photo or artwork using the Paperclip icon (📎).
   - Enter a prompt like "Create a similar image in this style", "generate the same type of image", 
     or "এই ছবির মতো একই স্টাইলের আরেকটি নতুন ছবি বানিয়ে দাও".
   - The system utilizes vision intelligence to analyze artistic medium, lighting, color palette, 
     and subject dynamics, synthesizes an aligned prompt, and generates a brand-new companion artwork!
3. Offline Dual-Frequency Enhancer:
   - Request image enhancement ("Enhance this photo" / "ছবিটি ক্লিয়ার করো") to upscale 2X and 
     sharpen skin and portrait details locally without external servers.

[বাংলা]
১. টেক্সট থেকে ছবি তৈরি: চ্যাট বক্সে সরাসরি লিখুন "একটি সুন্দর নদী ও নৌকার ছবি তৈরি করো"। সিস্টেম 
   স্বয়ংক্রিয়ভাবে FLUX.1 বা স্টেবিলিটি এআই দিয়ে হাই-কোয়ালিটি ছবি বানিয়ে সরাসরি চ্যাটে দেখাবে।
২. 🎨 একই ধরণের ছবি তৈরি (Same-Type Image - নতুন ফিচার): আপনার যেকোনো ছবি পেপারক্লিপ (📎) 
   আইকনে ক্লিক করে যুক্ত করুন এবং লিখুন "এই ধরণের আরেকটি ছবি বানাও" বা "Create a similar image"। 
   এআই আপনার ছবির আর্ট স্টাইল, লাইটিং ও ব্যাকগ্রাউন্ড বিশ্লেষণ করে ঠিক একই স্টাইলের সম্পূর্ণ নতুন ছবি তৈরি করবে।
৩. অফলাইন ছবি ক্লিয়ারিং: যেকোনো ঝাপসা ছবি এটাচ করে "ছবিটি পরিষ্কার করো" লিখলে ডুয়াল-ফ্রিকোয়েন্সি 
   অ্যালগরিদমের মাধ্যমে ২ গুণ শার্প ও স্পষ্ট করে দেবে।

4. CONTINUOUS LIVE VOICE WITH BARGE-IN / সার্বক্ষণিক লাইভ ভয়েস ও বার্জ-ইন
================================================================================
[ENGLISH]
* Hands-Free Live Dialogue (⚡ Live Mode):
  - Click the "⚡ Live" button on the right of the input bar to enter conversational live mode.
  - Speak naturally in English or Bangla. The app automatically detects speech via Voice Activity 
    Detection (VAD) and transitions through Listening ➔ Transcribing ➔ Thinking ➔ Speaking.
* Active Barge-In Interruption:
  - If the AI is speaking aloud and you wish to correct or interrupt it, simply speak!
  - The studio immediately halts audio playback, silences the speaker, and listens to your new query.
  - Acoustic Loopback Shield: Microphone gain is dynamically attenuated to `0.15` during playback, 
    preventing speaker sound from triggering false barge-in loops.
* Audio Hardware Devices (NEW in v2.0.0):
  - Navigate to **Settings > Voice & Audio > Audio Input & Output Hardware Devices**.
  - Explicitly select your desired physical Microphone (Input) and Speaker/Headphones (Output).
* Natural Conversational Pause:
  - Silence timeout calibrated to 1000–1300ms, providing comfortable pauses while speaking without 
    cutting you off mid-sentence.
* Cloned & Custom Voices Studio:
  - Use the "➕ Add Custom Voice" button to register personal voice IDs from Cartesia, Fish Audio, 
    ElevenLabs, or Microsoft Edge.

[বাংলা]
* লাইভ ভয়েস মোড (⚡ Live): ইনপুট বারের ডানপাশের "⚡ Live" বাটনে ক্লিক করুন। কোনো টাইপিং ছাড়াই মানুষের 
  মতো স্বাভাবিকভাবে কথা বলুন। বাংলা ও ইংরেজি উভয় ভাষায় নির্ভুলভাবে কথা বলা ও শোনা যায়।
* বার্জ-ইন (Barge-In) ইন্টারাপশন: এআই কথা বলার সময় আপনি কথা শুরু করলেই এআই সাথে সাথে থেমে যাবে এবং 
  আপনার নতুন কথা মনোযোগ দিয়ে শুনবে। ল্যাপটপ বা স্পিকারের শব্দের কারণে যেন নিজে নিজে না থেমে যায়, সেজন্য 
  স্পিকারের শব্দ ফিল্টার করার জন্য আধুনিক অ্যাকোস্টিক শিল্ড যুক্ত আছে।
* হার্ডওয়্যার অডিও ডিভাইস নির্বাচন (নতুন ফিচার): Settings > Voice & Audio পেজ থেকে আপনার পছন্দমতো 
  মাইক্রোফোন এবং হেডফোন/স্পিকার সরাসরি ড্রপডাউন থেকে সিলেক্ট করে নিতে পারবেন।

5. AUTONOMOUS REACT AGENT & 12 TOOLS / স্বয়ংক্রিয় রিঅ্যাক্ট এজেন্ট ও ১২টি টুলস
================================================================================
[ENGLISH]
* Multi-Turn ReAct Reasoning Loop:
  - Give complex, multi-step engineering prompts (e.g. "Inspect project files, fix the bug in 
    worker.py, run pytest, and export a report to Word docx").
  - The agent formulates a plan, executes actions, analyzes observations, and iterates to a solution.
* 12 Built-in Autonomous Agent Tools:
  1. `read_file`: Safe multi-encoding file reader.
  2. `write_file`: Path-guarded file writer restricted to user workspace folders.
  3. `list_directory`: Workspace explorer with recursive glob filtering.
  4. `search_files`: High-speed regex and textual search.
  5. `edit_file`: Surgical target-and-replace code editor.
  6. `run_command`: Sandboxed command shell execution with timeouts.
  7. `python_interpreter`: AST-secured in-process & subprocess Python REPL.
  8. `web_search`: Live real-time internet search via Tavily & DuckDuckGo.
  9. `export_document`: Multi-color document publisher (PDF, DOCX, XLSX, HTML, MD).
  10. `code_outline`: High-level symbol parser (extracts classes, methods, docstrings).
  11. `check_diagnostics`: Instant Python AST syntax diagnostics and linter.
  12. `git_tool`: Version control inspector (git status, diff, log, commit).
* ⚡ 1-Click "Allow All (Auto Run)" Permission Flow:
  - When the agent requests a sensitive action (editing a file or running a command), a permission 
    dialog (`ToolApprovalDialog`) appears with 3 options:
    - **`Deny Action`**: Aborts the operation immediately.
    - **`Allow Once`**: Authorizes only this single step.
    - **`⚡ Allow All (Auto Run)`**: Authorizes the agent for the entire active task session. The 
      agent works continuously without interrupting you with repetitive popups!
* Visual Code Changes & Diff Review Dialog (`CodeChangesReviewDialog` & `DiffTracker`):
  - View live green (`+`) and red (`-`) syntax-highlighted side-by-side diffs of all modifications.

[বাংলা]
* স্বয়ংক্রিয় রিঅ্যাক্ট এজেন্ট: যেকোনো বড় কাজ দিলে (যেমন: "ফাইলের কোড চেক করো, বাগ ফিক্স করো এবং টেস্ট রান 
  করে ওয়ার্ডে রিপোর্ট সেভ করো") এআই নিজের বুদ্ধিমত্তা দিয়ে ধাপে ধাপে কাজ সম্পন্ন করবে।

1. Launching the App:
   - Double-click the **Jakariya AI Studio** desktop shortcut, or launch from source:

   - Click the Gear Icon (⚙️) on the top header or status bar to open Settings.

   - In Settings > **AI Models**, assign your preferred models for Chat, Coding, and Reasoning.

     (Edge Neural TTS or Cartesia), and physical audio devices.
